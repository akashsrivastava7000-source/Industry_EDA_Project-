# Industry Performance Analysis using EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on an industry dataset to identify patterns, trends, and business insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
- Records: 15,000
- Features: Revenue, Employees, Customers, Industry, Region, Rating, etc.

## Analysis Performed
- Data Cleaning
- Missing Value Treatment
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Correlation Analysis
- Business Insights

## Project Files
- EDA_Project.ipynb
- EDA_Presentation.pptx
- Industry_Dataset.csv
